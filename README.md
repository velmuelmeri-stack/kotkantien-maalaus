# Kotkantien maalaus ja tapetointi

Kuvitteellisen maalaus- ja tapetointiyrityksen www-sivusto, tehty koulun näyttötyönä.

## Sivut

- **Etusivu** – hero-kuva, esittely ja nostot muille sivuille
- **Palvelut** – maalaus- ja tapetointipalvelut sekä upotettu YouTube-video
- **Värien testaus** – kaksi 16 värin palettia ja kaksi pintaa värien yhteensopivuuden kokeiluun
- **Galleria** – kuvaruudukko, kuva aukeaa isona klikkaamalla
- **Yhteystiedot** – yhteystiedot, yhteydenottolomake tarkistuksineen ja Google Maps -kartta

## Käytetyt tekniikat

- HTML5 ja CSS3
- JavaScript ja jQuery
- Bootstrap 5
- Bootstrap Icons
- Google Fonts (Roboto)
- Upotukset: YouTube ja Google Maps

## Kansiorakenne

- `css/` – tyylitiedosto
- `js/` – JavaScript-tiedostot
- `img/` – kuvat

## Kuvat

Kaikki sivuston kuvat ovat Pixabay-palvelusta (pixabay.com), ja niitä saa käyttää vapaasti Pixabayn lisenssin mukaisesti.
